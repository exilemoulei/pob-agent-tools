# `pob` command reference

Every subcommand with its flags, in one place. For when to use which, start with the recipes in [skills/pob/SKILL.md](../../skills/pob/SKILL.md); `pob <command> --help` is authoritative when this list and the CLI disagree.

```powershell
# Optimization flow: pob audit (dewater & gaps) -> rank-nodes / rank-gems / anoint / bench -> pob trade search (verified via PoB)
# Global output & slot targeting: --target <slug> (build slot; default POB_SLOT or main; a deprecated --slot alias exists only on commands without an equipment --slot and refuses equipment names such as `gloves`/`ring1` with exit 1); --compact (1-line JSON); --out <file> (UTF-8 no-BOM).
# Before the subcommand: pob --offline <command> (no engine update check, same as POB_OFFLINE=1); pob -V | --version.
# Exit codes: 0 ok; 1 bad request (bad arguments, PoE2 input, a share code that does not decode, a poe.ninja character that is not found, or a build code the engine rejects while it keeps running) and no engine installed (stderr says to run `pob bootstrap`); 2 usage error from the option parser (unknown option, missing or out-of-range value) and malformed JSON in --json-ops / --json-variants / --base-ops / --file; 5 daemon or engine fault (timeout, crash, any other engine error: `pob stop` and retry); `pob trade` uses 0..6 and exits 1 (not 2) on option-parser errors (docs/guides/trade.md).

# Lifecycle, Foreground Daemon, Engine Bootstrap/Update & Build I/O (127.0.0.1 + X-PoB-Token)
pob help [--brief|-b] [COMMAND]... [--json]                                            # Compact 1-screen CLI cheat-sheet (`--brief`, <20ms) or subcommand help
pob serve [--offline] [--proxy <url>] [--mirror <url>] [--port N] [--runtime-dir <dir>]               # Foreground persistent daemon (use IsDaemon:true in job-reaped shells)
pob bootstrap [--proxy <url>] [--mirror <url>] [--no-zh] [--from-dir <dir>] [--json]   # Install/seed slim managed engine (native LuaJIT _lua-host on Windows, zero pob-zh.exe; PobTools-zh bridge + zh-rCN/zh-rTW + PoB master)
pob update [--check] [--force] [--proxy <url>] [--mirror <url>] [--offline] [--json]   # Incremental SHA1 update (hot-reloads live daemon slots)
pob status [--json]                                                                    # Daemon PID, PoB/PobTools/Data versions, active lang, caps/winLuaHost, boolean Auth env status, updateStatus, all named slots (a slot whose saved build failed to restore at boot carries `restoreFailed`: error, codeFile, skipped)
pob lang [zh-CN|zh-TW|en] [--realm global|tw] [--json]                                 # Get or persist display language (`zh-CN`/`zh-TW`/`en`, `POB_LANG` overrides) and trade realm (`global` `pathofexile.com` or `tw` `pathofexile.tw`, `POB_REALM` overrides; `zh-TW` never auto-switches realm and asks for TW confirmation). Exit 1 for a locale the engine lacks, 5 when a running daemon does not answer; --json has dictLoaded, daemonSynced, realm, tradeBaseUrl, envIgnored
pob self-update [--check] [--version X.Y.Z] [--proxy <url>] [--mirror <url>] [--json]  # Update pob itself (standalone builds; signed release only); --check reports latest + the update command for this install; network/disk/swap failure exits 5
pob profile [ACCOUNT_OR_URL] [--realm pc|xbox|sony|cn] [--league L] [--proxy U] [--json] # 0-engine official profile character list (pathofexile.com public no-cookie, or poe.game.qq.com via env POE_CN_SESSID)
pob new [--class C] [--asc A] [--secondary-asc S] [--level N] [--target <slug>] [--json]
pob load [SOURCE] [--stage "<idx|title>"] [--spec S] [--item-set I] [--skill-set K] [--char "<name>"] [--league L] [--realm pc|xbox|sony|cn] [--target <slug>] [--json] # XML, Base64, 8 share sites, poe.ninja char URL, or official Intl/CN profile URL; also accepts `#stage=<idx|title>` fragment (`--stage` matches numeric stages by 1-based positional index; `--item-set`/`--skill-set` accept XML IDs); any other URL must be https on a public host (no localhost/LAN); a private official character is retried with env POESESSID/POE_COOKIE; the tree version follows the engine's latest (Ruthless leagues get its _ruthless tree)
pob save <out.xml> | pob export-code [--target <slug>] [--json]                        # Export XML (CLI disk write, R11) or Base64 code
pob switch-main [--spec S] [--skill-group G] [--skill N] [--part N] [--item-set I] [--skill-set S] [--config-set C] [--loadout L]
pob undo | pob redo | pob stop [--json]

# Read-Only Inspection, Grounding & One-Shot Diagnosis
pob ground "<prompt_text>" [--limit 8] [--json]                                        # <15ms daemon-free 3.30 entity cards + PoE2/patch trap alerts
pob diagnose [SOURCE] [-c|--compare REF] [-q|--ask "<text>"] [--stage S] [--ref-stage R] [--ref-spec S] [--ref-item-set I] [--ref-skill-set K] [--char "<name>"] [--league L] [--realm pc|xbox|sony|cn] [--keep <spec>]... [--no-auto-keep] [--rank|--no-rank] [--section all|summary|gaps|items|skills|cards|upgrades] [--top 5 (passing it enables ranking; slow)] [--target <slug>] [--ref-target <slug>] [--json] # One-shot: [Env (NOT PoE2) | rev=N] + Pinnacle audit + thresholdProbes (Suppression/+25%/+50% MRE/CoC ticks/attrs) + gaps/bricks/dead-supports/triggers + 3.30 cards + optional --rank upgrades (off by default; --rank, --top N or --section upgrades turn it on; a FullDPS build ranks nodes on FullDPS, several times slower) (or dual-build 3-baseline compare)
pob summary [--target <slug>] [--json]                                                 # [Env | rev=N] + Offence (Hit/DoT/FullDPS/Minion*), Defence (EHP/MaxHit/Res), Warnings
pob audit [--keep <spec>]... [--no-auto-keep] [--no-attribution] [--target <slug>] [--json] # [Env | rev=N] + Hard gaps + thresholdProbes + 4-dim water audit -> Pinnacle (per-item PoB attribution; --keep var|Flask N|flasks|gem|customMods|party)
pob map-regex [SOURCE] [--tier t16|t17|both] [--mode brick|safe] [--avoid TEXT] [--allow TEXT] [--preset-only] [--min-quant N] [--min-pack N] [--client-lang auto|en|zh-CN|zh-TW] [--max-len 250] [--target <slug>] [--json] # PoB-aware <=250-char 0-false-positive T16/T17 map filter regex (supports `--preset-only` daemon-free)
# Note: `pob map-regex` only outputs passive text for manual copy-paste into the stash search box and never interacts with the game client, game files, or overlays.
pob config list [--all] [--search "<sub >"] [--with-options] [--target <slug>] [--json] # Active/filtered ConfigTab vars + raw customMods
pob items [--slot "Weapon 1"|"#1"] [--all] [--raw] [--target <slug>] [--json]          # Equipped table, single slot, or all equipped + allocated jewels raw
pob item inspect (--slot S | --raw "<item text>" | --file f) [--want "Cold Resistance"]... [--limit 8] [--target <slug>] [--json] # Rare-item affix occupancy and bench candidates (unclamped --limit >= 1); uncertain matches never claim free slots
pob skills [--group main|1|"label"] [--target <slug>] [--json]                         # Skill groups or per-gem DPS tooltips
pob tree [SLOT] [--search "<kw>" ...] [--type Keystone|Notable|Mastery|Socket|Ascendancy ...] [--allocated|--unallocated] [--max-cost N] [--show-path] [--masteries] [--socket-radius <id|#1>] [--limit 100] [--full] [--json] # --limit 0 / --full returns all matching nodes
pob tree prune [SLOT] [--top 15] [--max-branch-pts 5] [--sort dps|ehp|pts] [--include-unsafe] [--target <slug>] [--json] # Connectivity-preserving 1..N pt branch pruning with attr/resist/mana/hit/trigger guardrails (<0.5s)
pob tree diff [--target <slug>] [--against ref] [--spec-a A --spec-b B] [--json]         # 5-section structured tree diff (points/ascendancy, keystones, wheels, masteries, clusters & sockets; intra-build `--spec-a/--spec-b` compares passive allocations only while equipped jewels/clusters reflect the slot's active ItemSet)
pob tree rank-wheels [SLOT] [--top 12] [--max-dist 12] [--max-pts 10] [--sort dps|ehp] [--all-tags] [--no-proxy-sockets] [--target <slug>] [--json] # <2s whole-wheel + unused `<nid>:<eid>` mastery ROI (`ΔDPS%/pt`, `ΔEHP%/pt`), hard vetoes, and strictly isolated `[Proxy Benchmark]` socket/outer-cluster ROI (`proxySocketBenchmarks`, omitted with `--no-proxy-sockets`)
pob calc "<kw1>" ["<kw2>" ...] [--group G] [--skill S] [--limit 20] [--max-breakdowns 30] [--no-breakdown] [--target <slug>] [--json] # Variadic EN/ZH get_calcs + calcs_breakdown formulas/tables (--max-breakdowns 0 expands all); rows are for `calcsSkill`. --group (index, main or name) with --skill (index, main or gem name) reads another group's active skill; --skill alone takes a gem or group name looked up in every group, or a group number. The Calcs tab is put back as it was

pob item unequip --slot S [--apply]

pob tree change [--allocate id1,id2:effectId]... [--deallocate id3]... [--allow-cascade|--no-allow-cascade] [--apply] # --allocate / --deallocate repeat and take comma lists; a node already in the asked state is reported as a no-op, one that cannot be reached is an error

# Batch ops (aliases in parentheses): config (config_set), flask (item_flask), item (item_try), item_db, item_edit, unequip (item_unequip, unequip_slot), anoint (item_anoint), tree (tree_change), tree_reset (reset_tree), import_tree_url, new_build, set_level, set_class (tree_set_class), switch_main, add_group (new_group, skill_new_group), delete_group (rm_group, remove_group), set_group, replace_group (skill_replace_group), skill, skill_set, skill_add, skill_rm
# e.g. --json-ops '[{"op":"skill_add","group":"main","gem":"Controlled Destruction","level":20},{"op":"tree","allocate":["Elemental Equilibrium"]}]'
# An op with a key it does not know is refused (a typo used to be ignored); remarks go in comment / note / why / desc / description / reason or any key starting with _. config variables go inside "set": {...}. A gem in "gems" is a 'Name[:level[:quality]]' string or an object (name | gemId, level, quality, enabled, count, skillPart, stageCount, enableGlobal1, enableGlobal2, allowIllegalLevel, allowLegacy); a gem object copied from `pob skills [--group G] --json` is accepted as is. replace_group keeps each kept gem's skill part, stage count and minion choice; skill / skill_add take skillPart and stageCount too.
# Field types are strict (exit 1 on a wrong type): tree allocate/deallocate take a list of node names or ids (a single name or id counts as one token, never split into characters; a string that is only comma-separated ids, such as "4397,27929", is split, but not inside a list), a tree op needs at least one node and switch_main at least one field; addMods/removeMods/gems take a list, and a single string is one mod or gem; integers reject booleans, lists, objects and fractions (12.5); booleans accept true/false, 0/1, on/off, yes/no, and a null flag such as apply means false (set_group's enabled / includeInFullDPS: null leaves the field as it is); replaceMods is a list of [old, new] pairs. Every step is checked before the first one runs. Results carry noopWarnings ("step N: ...") for nodes already in the asked state, and load/apply/undo/status carry persistWarning (printed as a [WARN] line in text output) while the slot file cannot be saved.
```
