# Contributing

Thanks for helping with pob4agents. The rules live in one place, so this file only points to them.

- [AGENTS.md](AGENTS.md) is the contributor guide, for people and agents alike: dev setup, the check gate, hard rules, conventions and commit style.
- [docs/architecture.md](docs/architecture.md) explains how the code fits together. Read it before changing code. To add a command, follow its "Adding a command" checklist.
- Pull requests fill in every section of the [pull request template](.github/pull_request_template.md), including the AI disclosure.
- Security problems go through [SECURITY.md](SECURITY.md), not a public issue.

pob4agents supports Path of Exile 1 only. Changes that weaken the PoE2 guardrails will not be merged.
